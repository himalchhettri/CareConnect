# CareConnect Professional Prototype Upgrade

This version upgrades the assessment prototype with a more complete healthcare-app experience while keeping the project dependency-free.

## Added / improved
- Professional Material 3 theme and consistent UI
- Modern splash, sign-in and registration screens
- Dynamic doctor search and speciality filters
- Correct doctor data through profile -> booking -> confirmation -> home -> appointments
- Dynamic booking dates and times
- Appointment confirmation, rescheduling and cancellation
- Professional dashboard with live appointment and reminder information
- Medication list and add-medication flow
- Medication reminders and dedicated reminders page
- Notification centre based on appointments/reminders
- Full Account page
- Edit profile
- Password/security page
- Notification preference switches
- Privacy/data information
- Help/About sections
- Logout with confirmation
- Responsive widths suitable for Chrome and Android layouts

## Prototype limitation
The project currently keeps user-created information in memory only. Data resets when the app process is fully restarted. Real production authentication, database storage, real push notifications, payment processing and medical-system integrations are intentionally not implemented in this assessment prototype.
